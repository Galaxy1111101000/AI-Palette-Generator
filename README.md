# Welcome to the Palette Generator

Have you ever had a theme or concept in mind but never the colours you need to express it?
Got a collection of pinterest photos but no way to know which colours you should use?

Well, never fear, the Palette Generator is here!

With the ability to generate a palette based on text or image, modify colours within the scheme, and even see it in action with a website preview, what's not to love?

(note: this project is still in development, but hopefully will launch in october if all things go according to plan)
